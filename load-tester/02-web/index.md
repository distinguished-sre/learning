## О чём тема

Что происходит между нажатием кнопки и ответом сервера, и где здесь может стать тесно.

Иди по порядку: каждый урок опирается на предыдущий. После объяснения выполни практику на учебном стенде, затем задание «сломай и почини»: измени одно условие, найди причину сбоя и проверь исправление. Вопросы с собеседований помогут проверить, можешь ли ты объяснить результат своими словами.

## Что ты сможешь после каждого урока

- **2.1** [Клиент, сервер и HTTP: запрос, ответ, коды](01-client-server-http.md): Прочитаешь HTTP-запрос и объяснишь код ответа сервера.
- **2.2** [REST API, JSON и авторизация](02-rest-json-auth.md): Выполнишь запрос к API с JSON и токеном авторизации.
- **2.3** [Из чего состоит бэкенд: приложение, база, кэш, пулы](03-backend-anatomy.md): Проследишь путь запроса через приложение, базу, кэш и пул.
- **2.4** [SQL и PostgreSQL: таблицы, запросы, индексы](04-sql-basics.md): Напишешь SQL-запрос к PostgreSQL и объяснишь назначение индекса.
