# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Одностраничный лендинг-гайд «Путь в автоматизацию и нагрузочное тестирование с нуля» для человека без опыта в IT. Живёт на GitHub Pages: https://distinguished-sre.github.io/load-tester/

Весь продукт — четыре файла в корне: `index.html` (разметка + стили + скрипты), `bg.jpg` (фон), `og.jpg` (превью для соцсетей, ровно 1200×630), `README.md`. Сборки, package.json, зависимостей и тестов нет и заводить их не нужно.

## Команды

```bash
# локальный просмотр
python3 -m http.server 8777 --bind 127.0.0.1   # затем http://127.0.0.1:8777/index.html

# проверка размеров ассетов
sips -g pixelWidth -g pixelHeight og.jpg

# пересжатие ассетов (исходники PNG держат вне репозитория)
sips -s format jpeg -s formatOptions 62 --resampleWidth 1600 /tmp/bg_src.png --out bg.jpg
sips -s format jpeg -s formatOptions 78 -z 630 1200 /tmp/og_src.png --out og.jpg
```

Деплой: `.github/workflows/deploy.yml` публикует корень репозитория в GitHub Pages при каждом push в `main` (кроме правок только `README.md`). Отдельного шага сборки нет — что в `index.html`, то и на проде.

## Архитектура `index.html`

Порядок в файле: `<head>` с мета-тегами и inline-скриптом анимации → `<style>` → `<main>` с семью пронумерованными `<section>` → три `<script>` в конце.

**Блокирующий inline-скрипт в `<head>` (строки ~24–55)** включает reveal-анимации: вешает класс `anim` на `<html>` и через IntersectionObserver добавляет `in` на `.hero`, `section`, `.track`. Отключается при `prefers-reduced-motion` и на ширине ≤700px. Есть `try/catch`-фолбэк, который просто показывает всё — не ломай его: без него ошибка в скрипте оставит страницу пустой.

**Стили** — один `<style>` на CSS-переменных в `:root` с тёмной темой через `@media (prefers-color-scheme: dark)`. Цвета берутся только из переменных; тёмная тема должна получать значение вместе со светлой. Фон — `body::before` с `bg.jpg` и `body::after` с полупрозрачной «вуалью» (`--veil`), поэтому контраст текста зависит от обеих переменных сразу.

**Двуязычность (второй `<script>`)** — три разных механизма, при правке текста нужно понимать, какой применён:
1. `data-en="…"` на элементе — простой текст. RU-версия при загрузке снимается из `textContent` в `data-ru`, поэтому RU живёт прямо в разметке. `data-en-aria` работает так же для `aria-label` (используется на inline-SVG).
2. Словарь `EN_HTML` в скрипте — для блоков со ссылками и вложенными тегами (`howto`, `rule1..3`, `calloutP`, `nnV`). Такой блок обязан иметь `id`, совпадающий с ключом; RU-версия остаётся в разметке.
3. `EN_PROMPT` — template literal с английской версией текста промпта; RU-версия лежит в `<pre id="prompt">`. **Правки промпта всегда парные: RU в `<pre>` и EN в `EN_PROMPT`.** Внутри `EN_PROMPT` нельзя допускать неэкранированных `` ` `` и `${` — проверка: `grep -c '\${' index.html` должно оставаться 0.

Выбор языка хранится в `localStorage` под ключом `lang`, начальный берётся из `navigator.language`. `apply()` попутно меняет `document.title`, `meta[name=description]` и `<html lang>`.

**Третий `<script>`** — UI-мелочи: копирование промпта (`navigator.clipboard` + фолбэк на `execCommand`), полоска прогресса скролла `#progress`, плавающая кнопка `#jump` (прячется, когда `#start` в зоне видимости), подсветка `.stop` в дорожной карте, делегированный обработчик кликов по `a[href="#start"]` — делегирование обязательно, потому что ссылки внутри переводимых блоков пересоздаются при смене языка.

**Подсказка по ОС** (`#osHint`) определяется по `navigator.platform`/userAgent и берёт текст из объекта `OS_HINT` (ключи `mac`/`win`/`linux`, внутри `ru`/`en`); на мобильных скрывается.

## Что важно держать

- Никаких внешних зависимостей, кроме шрифтов Google Fonts — вся логика inline. Страница должна работать как один статический файл.
- Диаграммы — inline-SVG с классами (`c-*`, `fa-*`) и `aria-label`/`data-en-aria`; растровых иллюстраций нет.
- Тексты на русском — обычная типографика: тире «—», кавычки «ёлочки», буква «ё».
- Вес страницы под контролем: `index.html` ~100 КБ, ассеты пережаты. Новые тяжёлые файлы не добавлять.
- При изменении заголовка/описания правь их в четырёх местах: `<title>`, `meta[name=description]`, og-теги и переменные `titleEn`/`metaEn` в скрипте.
