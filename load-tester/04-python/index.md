## О чём тема

Ровно столько языка, сколько нужно для автотестов и сценариев нагрузки.

Иди по порядку: каждый урок опирается на предыдущий. После объяснения выполни практику на учебном стенде, затем задание «сломай и почини»: измени одно условие, найди причину сбоя и проверь исправление. Вопросы с собеседований помогут проверить, можешь ли ты объяснить результат своими словами.

## Что ты сможешь после каждого урока

- **4.1** [Первая программа: интерпретатор, переменные, типы](01-first-program.md): Запустишь программу Python с переменными разных типов.
- **4.2** [Условия, циклы, списки и словари](02-conditions-loops.md): Обработаешь список тестовых данных циклом и условием.
- **4.3** [Функции, модули и исключения](03-functions-errors.md): Выделишь функцию в модуль и обработаешь исключение.
- **4.4** [Файлы, JSON и CSV: данные для тестов](04-files-json-csv.md): Прочитаешь JSON и сохранишь результаты проверки в CSV.
- **4.5** [Виртуальное окружение, pip и HTTP-запросы из кода](05-venv-requests.md): Создашь venv и отправишь HTTP-запрос из Python.
- **4.6** [Классы и объекты: зачем они Locust](06-classes.md): Опишешь класс пользователя с состоянием и методами.
- **4.7** [pytest: первые тесты](07-pytest.md): Напишешь тест pytest с проверкой результата.
