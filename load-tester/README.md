# Нагрузочное тестирование и мониторинг с нуля

Бесплатный курс для человека без опыта в IT: от первого терминала до поиска узких мест под нагрузкой и собеседования на роль нагрузочного тестировщика с мониторингом. 13 тем, 52 урока, около 128 часов: 5 занятий в неделю по 1,5–2 часа, это около трёх месяцев.

- Курс: https://distinguished-sre.github.io/load-tester/course/
- Гайд «С чего начать» с промптом нейросети-преподавателя: https://distinguished-sre.github.io/load-tester/

## Как устроен курс

Каждый урок: зачем это нужно, картина целиком со схемой, теория с аналогиями и разобранными примерами, практика с ожидаемым выводом, «сломай и почини», словарик и вопросы с собеседований. Механизмы показаны визуально: блок-схемы, анимации очередей и пути запроса, графики задержек.

Сквозной проект «Магазин» (`project/shop`): интернет-магазин на Python (FastAPI) с PostgreSQL, Redis и заглушкой оплаты, с Prometheus, Grafana, Loki и Alertmanager рядом. Ученик не пишет сервис, а тестирует его, как на работе: автотесты API, сценарии Locust и k6, дашборды, алерты, поиск и доказательство заложенных узких мест.

```bash
git clone https://github.com/distinguished-sre/load-tester.git ~/load-tester
cd ~/load-tester/project/shop && cp .env.example .env
docker compose --profile monitoring up -d --build --wait
```

Темы: Linux, как устроен веб-сервис, Git, Python, Docker и стенд, автотесты API и CI, метрики, логи и алерты, теория производительности, Locust, k6, поиск узких мест, нагрузочное тестирование как процесс, финал с тестовым заданием и пробными собеседованиями.

## Устройство репозитория

- `index.html`, `bg.jpg`, `og.jpg`: лендинг-гайд, статический, без сборки, двуязычный.
- `_data/course.yml`: порядок тем и уроков; `NN-тема/`: уроки в Markdown; `course/`, `schedule.md`, `_layouts/`, `_includes/`, `assets/`: сайт курса на Jekyll.
- `project/shop/`: стенд «Магазин»; `.github/workflows/stand.yml` поднимает его и прогоняет эталонные тесты.

Публикация: GitHub Pages, сборка Jekyll в GitHub Actions при push в `main`.
