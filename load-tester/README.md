# Нагрузочное тестирование и мониторинг с нуля

**Узнай, выдержит ли сайт толпу.** Бесплатный курс для человека без опыта в IT: от первого терминала до поиска узких мест под нагрузкой и пробных собеседований.

13 тем · 57 уроков · около 170 часов · 5 занятий в неделю по 1,5–2 часа, около пяти месяцев

## Что это за профессия

Краш-тест, только для сайта. Банк, маркетплейс или доставка должны выдержать распродажу и час пик. Инженер по нагрузке приводит на тестовую копию сайта тысячи «покупателей», смотрит на приборы и находит, что сломается первым, до того как это случится с живыми людьми.

1. **Приводишь толпу:** пишешь сценарий покупателя, программа повторяет его за тысячу человек сразу.
2. **Смотришь на приборы:** метрики, логи, трейсы и алерты показывают, что происходит внутри.
3. **Находишь причину:** не «сайт тормозит», а «вход не успевает, когда людей больше трёхсот», с цифрами и отчётом.

## Как учишься

Весь курс ты работаешь с учебным интернет-магазином: вход, каталог, корзина, оплата. Писать его не нужно, ты его проверяешь, как на работе. Внутри спрятаны настоящие проблемы: медленный вход, история заказов без индекса, утечка памяти, оплата, которая тормозит весь магазин, отсутствие кэша.

Каждое новое слово объясняется там, где встретилось. Механизмы показаны схемами и анимациями, в каждом уроке практика с ожидаемым выводом, «сломай и почини», вопросы с собеседований и готовые запросы к нейросети (ChatGPT, Claude, DeepSeek, Qwen) с тем, что проверить в ответе.

## Пять этапов

| Этап | Темы | Что умеешь после |
|---|---|---|
| Освоиться | 1–3: Linux, веб-сервис и HTTP, Git | работаешь в терминале, понимаешь, как устроен сайт, хранишь работу на GitHub |

Инструменты: Linux, Git, Python, Docker, PostgreSQL, Redis, Prometheus, Grafana, Loki, Tempo, Alertmanager, Locust, k6, GitHub Actions.

## Что будет в конце

- портфолио на GitHub: тесты, сценарии, дашборды и графики;
- отчёт о нагрузочном тесте: где предел и что исправить;
- решённое тестовое задание за один день;
- сотни вопросов с разбором и два пробных собеседования: на инженера по нагрузке и на инженера мониторинга.

Честно: курс не гарантирует работу. Он даёт базу и портфолио. На старте реалистичны стажировка или младшая роль в тестировании, поддержке, эксплуатации или мониторинге.

## Что понадобится

Компьютер с Ubuntu 24.04 или 26.04 (или Windows с WSL2, или Mac с виртуальной машиной), от 8 ГБ памяти и 40 ГБ на диске. Все программы бесплатные.

Стенд «Магазин» поднимается так (команды разбираются в теме 5):

```bash
git clone https://github.com/distinguished-sre/load-tester.git ~/load-tester
cd ~/load-tester/project/shop && cp .env.example .env
docker compose --profile monitoring up -d --build --wait
```

Нагрузку давай только на свой локальный стенд: нагружать чужие сайты нельзя.

## Устройство репозитория

- `index.md`, `_layouts/home.html`: главная курса; `ai.md`: страница «ИИ-помощник» с промптом преподавателя; `schedule.md`: расписание.
- `_data/course.yml`: порядок тем и уроков; `NN-тема/`: уроки в Markdown; `_layouts/`, `_includes/`, `assets/`: оформление и виджеты.
- `project/shop/`: стенд «Магазин»; `.github/workflows/stand.yml` поднимает его и прогоняет эталонные тесты.

Сайт собирает Jekyll в GitHub Actions при push в `main` и публикует на GitHub Pages.
