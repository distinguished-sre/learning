# Путь в автоматизацию и нагрузочное тестирование с нуля

Одностраничный гайд для человека без опыта в IT, который хочет освоить две ценные инженерные специализации: автоматизацию тестов (AQA/SDET) и нагрузочное тестирование (performance). Объясняет, что это за работа и зачем, показывает путь обучения по шагам и даёт готовый текст для нейросети, с которого начинается практика.

Открыть гайд: https://distinguished-sre.github.io/load-tester/

## Что внутри
Профессия простыми словами, карта из девяти этапов (тонкая база и быстро в код: автотесты API и UI, метрики, нагрузка, CI/CD) и промпт, который превращает сильную нейросеть в личного преподавателя.

Промпт задаёт преподавателю рамки: знакомство по одному вопросу, один маленький шаг на сообщение с проверкой понимания, код студент набирает руками, разбор каждой команды до запуска, нагрузка — только против локального приложения, и блок «Состояние» для переноса контекста между сессиями и чатами.

## Устройство
Один файл `index.html` — разметка, стили и скрипты внутри, без сборки и зависимостей. Страница двуязычная: переключатель RU/EN подменяет тексты из `data-en`, словаря `EN_HTML` и константы `EN_PROMPT` в скрипте, выбор языка запоминается в `localStorage`. Ассеты: `bg.jpg` (фон) и `og.jpg` (превью для соцсетей, 1200×630).

## Публикация
Статическая страница на GitHub Pages, деплой через GitHub Actions при каждом push в `main`.
